#### Description:

FocusFlow Study Planner is a Python command-line application that helps students organize their school tasks and decide what they should work on first. I created this project because students often have many assignments due at the same time, and it can be hard to know which task is actually the most important. Sometimes a student chooses the easiest task first, even when another assignment is due sooner or needs more time. This program solves that problem by saving tasks, calculating a priority score, sorting assignments, and building a realistic daily study plan based on how many hours the student has available.

The program runs in the terminal with a simple menu. When the user starts the app, they can choose to add a new task, view all tasks, mark a task as completed, build a study plan for today, or save and exit. Each task includes a subject, a short description, a due date, a difficulty level from 1 to 5, and the estimated number of hours required. The application uses this information to calculate a priority score. Tasks due sooner receive a higher score because they are more urgent. Difficult tasks and tasks that need more hours also receive higher scores because they require more planning and effort. This makes the app more useful than a normal to-do list because it does not only store tasks; it also helps the user make a decision.

The main file of the project is `project.py`. This file contains the `main` function and all of the custom functions used by the program. The `main` function controls the menu and keeps the application running until the user chooses to save and exit. The function `normalize_subject` cleans up subject names by removing extra spaces and converting the name to title case. This means that if the user types something like “  python   programming ”, the program stores it as “Python Programming.” I added this function because I wanted the saved tasks to look organized and consistent.

The `parse_due_date` function checks that dates are entered in the correct `YYYY-MM-DD` format and converts the text into a real Python date object. This is important because the program needs to compare the due date with today's date in order to calculate urgency. The `calculate_priority` function is one of the most important parts of the project. It uses the due date, difficulty, and estimated hours to create a numerical priority score. I made this design choice because I wanted the app to be simple enough to understand, but still smart enough to give useful recommendations. The formula is not meant to be perfect, but it gives a reasonable result: urgent, difficult, and time-consuming tasks move to the top of the list.

The `create_task` function builds a complete task dictionary after validating the user input. It makes sure that the subject and description are not empty, that the date is valid, that the difficulty is between 1 and 5, and that the estimated hours are greater than zero. This helped me avoid bugs caused by bad user input. The `sort_tasks_by_priority` function returns tasks ordered by priority, with unfinished tasks shown first. Completed tasks are moved below open tasks so the user can still see them but does not confuse them with active work. The `build_daily_plan` function creates a plan for the day by selecting high-priority tasks that fit within the available study time. For example, if the user only has two hours, the program will not choose a task that needs five hours.

The project also includes several menu helper functions. The `add_task_menu` function collects input from the user and adds a new task. The `view_tasks_menu` function prints the tasks in a readable format. The `complete_task_menu` function lets the user mark an assignment as done. The `daily_plan_menu` function asks how many hours the user has and then displays a suggested plan. The `load_tasks` and `save_tasks` functions use a JSON file called `tasks.json` to store information. I chose JSON because it is easy to read, easy to write, and does not require an outside database. This was a good design choice for a student project because it keeps the application simple while still allowing tasks to remain saved after the program closes.

The second required file is `test_project.py`. This file contains pytest tests for the most important custom functions. I tested `normalize_subject`, `parse_due_date`, `calculate_priority`, `create_task`, `sort_tasks_by_priority`, `build_daily_plan`, and `format_task`. These tests check normal cases and error cases. For example, the tests confirm that an invalid date raises a `ValueError`, that difficulty values outside the range of 1 to 5 are rejected, and that urgent tasks receive a higher priority than tasks due later. The tests helped me check that the logic of the program works even before running the full menu manually.

The third file is `requirements.txt`. This file lists `pytest`, which is needed to run the test file. The actual project does not need many external libraries because it uses Python's built-in modules such as `json`, `datetime`, and `pathlib`. I kept the number of dependencies low because it makes the project easier to install and run in a Codespace or on another computer.

One design choice I debated was whether to make this project a web application or a terminal application. A web app might look more modern, but it would also require Flask, HTML, routes, templates, and more setup. I decided that a command-line program was better for this project because the main goal was to show strong Python logic, functions, testing, input validation, and file storage. Another design choice was how to calculate priority. I considered only sorting by due date, but that would ignore how hard and time-consuming an assignment is. I chose a formula that combines urgency, difficulty, and time because it better matches how students actually decide what to study.

A good outcome for this project was to create a working app that saves tasks and displays them clearly. A better outcome was to include a priority system and pytest tests. The best outcome was to add the daily planning feature, because that makes the project more practical. Overall, FocusFlow Study Planner is a useful student productivity tool and a complete Python final project. It uses multiple functions, persistent storage, input validation, sorting logic, and automated tests. It is simple enough for a beginner to explain during a viva-voce review, but complex enough to show real design decisions and useful functionality.
